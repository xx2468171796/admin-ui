# 更新日志

这里是面向使用者的摘要。逐条的改动、风险和升级说明在包里的 `CHANGELOG.md`。

> 版本号规则：大版本 = 删东西（附迁移表和审计规则）；次版本 = 只新增导出，被替代的写法先标 `@deprecated`，下一个大版本删除。

## 8.3.0 · 未发布

- **多维表格首屏变轻**：只读打开一张表首屏 JS 158 → 113 KB（gzip，含 TanStack）；筛选 / 分组 / 排序 / 字段 / 填色面板的内容、格内编辑器、灯箱按需下载。顺带修了摇树：核心入口 25.7 → 22.9 KB。
- **`CommandPalette globalShortcut`**（或 `AdminShell globalShortcut`）：刚打开的页面按 Ctrl / ⌘ K 也能打开；打字时只认带 Ctrl / ⌘ 的组合。
- **组织选人**：`defaultFocus` 晚到也会定位；懒加载的添加框不再吞掉第一次点击；`lockedHint` 只在没有原因时补上。
- **成员「添加成员」**：`TenantMembersPage` / `GovernanceConsole` 给了 `orgSource` 就用组织选人选人，不再手填用户编号。
- 本站首页单独打包：入口 + 首屏 CRM 约 195 KB（gzip），原来要先下载全部文档和全部演示。

## 8.2.0 · 未发布

开源准备：库里去掉了所有内部名称和引用，地区默认值改成中性、可配置。

- **地区默认值**：`AdminProvider defaults={{ timeZone, currency, phoneCountry }}`；没设置时时区跟浏览器、金额不带币种、电话区号按浏览器语言的地区；币种列表按 ISO 代码排序、国家列表按地区代码排序。
- 新子路径 `@adminui/react/settings`（字典 / 参数页），旧名 `/peizhi` 在 8.x 保留、已弃用。
- `admin-ui-audit` 认 npm 别名：从 package.json 读出指向本包的别名，另可 `--package <名字>`。
- 记录详情布局 / 仪表盘标签的范围字改成「团队默认」，可用 `editor.labels` / `scopeLabels` 改回自己的说法。
- 组织选人页换成真组件演示。

## 8.0.0 · 2026-10-08

干净的大版本：被新组件取代的旧写法全部删掉，**不留兼容层**；CSS 按组件拆开，页面只带用到的样式。

- 核心样式 gzip 108.8 → **24.1 KB**；其余 37 块样式由用到它的组件自己引入，懒加载的子路径连 CSS 一起按需加载。
- 新增小 / 中 / 大三档起步样板（`examples/small`、`examples/starter`、`examples/large`）和体积预算门禁。
- 审计新增 6 条规则：`removed-api`、`removed-prop`、`removed-class`、`removed-css-var`、`legacy-tone`、`deep-import`；新命令 `npx @adminui/react audit <目录>`。
- 记录详情改成第一次打开时才加载。
- 升级方法见 [升级到 8.0](migration.html)。
