# 页面模板

**先选模板，再写页面。** 后台里的页面翻来覆去就那么几种：工作台首页、资源列表、指标 + 列表、统计看板、设置页、向导……每种的布局是定死的，内容按业务换。这样同一个系统里的页面长得像一家人，AI 写页面时也不会每次重新发明布局。

下面每个模板都是用组件库真实渲染的整页，在预览里切到「手机 390」可以看手机布局。

<!--cards-->

## 全部 17 个模板

| 编号 | 模板 | 用在哪 |
|---|---|---|
| T01 | 工作台首页 | 登录后第一屏：现在怎么样、要我做什么、去哪 |
| T02 | 资源列表页 | 管一类会增长的对象：找、筛、逐行操作 |
| T03 | 指标 + 列表页 | 先看几个数是否正常，再处理列表 |
| T04 | 统计看板页 | 一段时间的用量 / 花费 / 趋势复盘 |
| T05 | 分区合并页 | 一个菜单项下几个相关页面 |
| T06 | 日志 / 时间线页 | 审计日志、任务记录、告警历史 |
| T07 | 关系图 / 实时监控页 | 谁连着什么、拓扑、监控墙 |
| T08 | 设置 / 表单页 | 一组配置项、授权信息、个人设置 |
| T09 | 权限配置页 | 谁能对哪些对象做什么 |
| T10 | 工具 / 工作区页 | AI 助理、终端这类整屏工具 |
| T11 | 进度 / 工作项页 | 任务、长流程的进度 |
| T12 | 向导页 | 导入、接入、激活这类多步操作 |
| T13 | 个人页 | 我的首页、我的接入 |
| T14 | 记录详情 | 所有列表行的「详情」 |
| T15 | 表格工作区 | 多维表格、CRM 这类一个模块一整屏的工作区 |
| T16 | 公开页 | 不用登录、从链接打开的页面：填表、访客看记录、密码门 |
| T17 | 搭建器 | 拖组件搭看板、表单 |

每个模板的骨架、用到的组件和示例代码在包里的 `PAGE-TEMPLATES.md`；机器可读的版本是 `import { PAGE_TEMPLATES } from "@adminui/react/catalog"`。
