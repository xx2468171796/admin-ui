# 后台界面设计规范

adminUI 只有一种外观：中性导航、清晰层级、紧凑密度、一套色卡。信息层级参考 Cloudscape 资源管理，密集表格参考 Carbon（见 [TABLES.md](TABLES.md)）。没有引入其他组件库、AWS / IBM 品牌素材或远程字体。样式只作用在 `.adminui` 内。写页面前先看 [AI-RULES.md](AI-RULES.md) 的组件套件：页面只用套件里的组件和色卡里的颜色。

## 1. 颜色：色卡

### 1.1 规则

- **一套色卡 = 一个主色系 + 3 种点缀色**：注意（attention，琥珀类，对应 `warning`）、异常（danger，主色的互补色）、信息（info，安静的第三色，少用）。全站不出现第五种颜色。
- **「正常 / 成功」用主色系**，没有单独的绿色。状态徽标、勾、进度、选中、链接、主按钮都是主色系。
- 中性色（画布、面板、线、正文、次要文字）都带一点主色调，整页读起来是同一家族。
- **不画装饰色条**：面板、卡片、提示条不加左侧 / 顶部彩色竖条或横条。状态用图标 + 文字 + 浅底表达，不只靠颜色。
- 业务组件不写死颜色（禁 `#3264d6`、`text-blue-*` 之类），只用 `var(--aui-*)` token。
- **唯一例外：录音红**。录音按钮、录音中的波形和计时状态用异常色（`--aui-record` = `--aui-danger`），这是通用惯例，只用在录音上，见 §1.5。

### 1.3 项目怎么选色卡

```tsx
import { AdminProvider, AppearanceButton, NotificationProvider } from '@adminui/react';
import '@adminui/react/styles.css';

export function AdminRoot({ children }: { children: React.ReactNode }) {
  return <AdminProvider storageKey="my-project:admin" palette="forest" mode="system">
    <NotificationProvider>{children}</NotificationProvider>
  </AdminProvider>;
}
// 顶栏：<AdminShell headerActions={<AppearanceButton />} … />
```

- `palette` 收三种值：色卡 id（`"forest"` 等，默认 `"forest"`）、完整的 `PaletteSpec`（`{ id, name, primary, attention, danger, info }`）、或一个品牌色 `"#rrggbb"`（只换主色系，点缀色沿用森林绿那三种，主色自动调深浅保证白字清晰）。
- `AppearanceButton` 放顶栏：太阳 / 月亮按钮点开小弹层——浅色 / 深色 / 跟随系统、六个色卡色块、字号、最后一行「自定义品牌色…」（只有它弹对话框）。选择按 `storageKey + ":mode" / ":palette" / ":font-size"` 存在浏览器，用户选过的优先于项目的 `palette` / `mode`（宿主自己改 `mode` 时又以宿主为准），选回项目默认色卡就清掉记录。只要字号时可以单独放 `FontSizePicker`。账号菜单里也有「外观」一行（`ColorModeChoice`）。
- 代码里读当前颜色：`useAdminTheme().palette`（`primary / ink / soft / wash / attention / danger / info / series / vars`），换色用 `setPalette(id | spec | "#hex")`。纯函数 `createPalette`、`contrast`、`mix`、`validColor`、`isPaletteId`、`paletteById`、`PALETTES`、`DEFAULT_PALETTE` 可在服务端或测试里用。
- 明暗与色卡独立：`mode="light" | "dark" | "system"` 是项目默认；`useAdminTheme().modeChoice / setMode` 读写用户的选择。

### 1.4 token

| token | 用途 |
|---|---|
| `--aui-primary` / `--aui-ink` / `--aui-primary-mid` | 主操作、链接、选中、图标 / 深一级（成功文字）/ 中间色 |
| `--aui-soft` / `--aui-soft-strong` / `--aui-wash` / `--aui-border` | 主色浅底、选中底、极浅底、主色描边 |
| `--aui-success*` | 等于主色系（`success` / `success-soft` / `success-line`） |
| `--aui-warning*` / `--aui-danger*` / `--aui-info*` | 三种点缀色，各有 `-soft`（浅底）和 `-line`（描边） |
| `--aui-canvas` / `--aui-surface` / `--aui-surface-subtle` / `--aui-tile` | 画布、面板、次级面、字段方块 |
| `--aui-text` / `--aui-secondary` / `--aui-note` / `--aui-line` | 正文、次要文字、备注、分隔线 |
| `--aui-neutral-1` … `--aui-neutral-4` | 纯中性文字阶（不带主色调），只给文档阅读 / 编辑器正文区，见 §1.6 |
| `--aui-sidebar` / `--aui-sidebarDeep` | 侧栏底色（由主色加深生成） |

图表：颜色全从色卡来——类别用选项标签色（`vizCategory(i)`，第 9 个起并进「其他」），单系列 / 有序用主色深浅（`VIZ_BRAND` / `vizBrandStep`），`AdminChart` 用 `chartColors(palette)` 换成当前色卡；状态色不当系列色。细节见 §2.5 和 [DASHBOARDS.md](DASHBOARDS.md) §12。

### 1.5 媒体上的颜色与录音红

照片、视频画面本身不随明暗变，叠在上面的东西在浅色、深色下都用「色卡最深色混出的遮罩 + 浅字」，不写死 `#fff` / `#000`：

| token | 用途 |
|---|---|
| `--aui-on-media` | 媒体上的文字和图标（时长、「封面」、播放键、上传中百分比） |
| `--aui-media-scrim` / `--aui-media-scrim-strong` | 播放圆、上传中遮罩 / 时长和封面角标的底 |
| `--aui-media-stage` | 大图预览里图片、视频的舞台底色 |
| `--aui-overlay` | 弹框遮罩（大图预览沿用） |
| `--aui-record` / `--aui-record-soft` / `--aui-record-line` | 录音红（= 异常色那一组） |

- 没有缩略图的媒体 = 中性底（`--aui-surface-subtle`）+ 类型图标；不画渐变插画。文件类型标签（PDF、XLS）不上色，所有类型一个颜色。
- 录音红只用在：录音 / 结束并保存的大圆键、录音中的状态字和小红点、录音波形、按住说话按下后的按钮和「松开取消」。播放器、上传、普通按钮仍是主色系。

### 1.6 文档正文的纯中性灰

后台的文字色都带一点主色调（§1.1）；读写大段文字的区域（知识库 / 文档阅读页、编辑器正文、长说明）改用不带色调的纯中性灰阶，读起来和飞书文档一样干净：

| token | 浅色 | 深色（森林绿面板上） | 用途 | 对比度（对面板） |
|---|---|---|---|---|
| `--aui-neutral-1` | `#1f2329` | `#e3e5e8` | 正文、标题 | ≥ 7:1 |
| `--aui-neutral-2` | `#646a73` | `#a7acb3` | 次要、备注、元信息 | ≥ 4.5:1 |
| `--aui-neutral-3` | `#8f959e` | `#7f858d` | 占位、大字、图标 | ≥ 3:1（不写小字正文） |
| `--aui-neutral-4` | `#bbbfc4` | `#5a5f66` | 禁用 | 不保证 |

- 用法：正文容器加 `className="aui-neutral-text"`（`Pane className="aui-neutral-text"` 也行）。子树里 `--aui-text` → 1、`--aui-secondary` → 2、`--aui-note` → 2（备注不用 3：3 级对白底只有 3:1，不够小字的 4.5:1），组件照常用 `var(--aui-text)` 等就自动跟着换；主色、链接、点缀色、线、底色都不变。
- 只用在文档区；列表、表单、导航、看板继续用带主色调的 `--aui-text` / `--aui-secondary` / `--aui-note`（这三个的值没有变）。
- 深色由 `createPalette` 按当前色卡的面板色算（`palette.neutralText`），换色卡时保证上表的对比度；值本身是纯灰，不随色卡变色调。

### 1.7 选项 10 色（标签、下拉选项、填色、视图色块）

选项 / 标签 / 字典值的颜色是固定的 10 色，全部从当前色卡算出来，换色卡和深色模式自动跟随：

| tone | 名字 | 怎么来的 | 例 |
|---|---|---|---|
| `green` | 绿 | = 主色（`--aui-primary`） | 官网表单、智能门锁 |
| `teal` / `blue` / `violet` / `pink` | 青 / 蓝 / 紫 / 粉 | 取**异常色**的明度和彩度，只转色相（OKLCH 195° / 255° / 300° / 350°，彩度封顶 0.09–0.13） | 需求确认 / 首通 / 转介绍 / 影音 |
| `red` / `orange` / `yellow` / `olive` | 红 / 橙 / 黄 / 橄榄 | 同上（28° / 58° / 85° / 125°，橙、黄稍亮一点） | 丢单 / 谈判 / 报价 / 装机 |
| `gray` | 灰 | = 备注色（`--aui-note`） | 其他、待分配 |

- 每色四个变量，由 `createPalette` 预先算好写在根元素上（不依赖浏览器的 `oklch(from …)`）：`--aui-option-<色>`（圆点、色块）、`-soft`（标签底）、`-text`（标签字，对底 ≥ 4.5:1）、`-solid`（实心标签底，对白字 ≥ 4.5:1）。纯函数 `optionHueColors` / `createPalette().options` 可在服务端或测试里用。
- **实心**（`greenSolid`、`redSolid` …）只给一个「最想被看见」的值（例：成交）；很密的地方（表头、分组、图例）用小圆点 `.aui-tone-dot` + 文字。
- **形状统一**：圆角 6 的软方块、不加边框；格子 20px、字段行 22px（`data-size="md"`）、表单 26px（`data-size="lg"`）。同一个值在三个地方颜色和形状不变，只变尺寸。
- **新写的数据只用这 20 个名字**（10 色 + 各自的 `xxxSolid`）。**读存量数据**用 `legacyTone(name)`（只读、不写回旧名，`optionTone` 已内置它），旧名一一对上：`brand` → `green`、`brandMid` → `teal`、`info` → `blue`、`warning` → `yellow`、`danger` → `red`、`neutral` → `gray`、`solid` → `greenSolid`，存量数据不用迁移。颜色名（`orange`、`purple`、`红色`）由 `optionTone` 对上，`#hex` 由 `colorTone` 按色相对到最近的色，其他任意颜色显示灰。
- 选色用 `OptionSwatchPicker`（10 个色块 5 × 2 + 「实心」开关 + 预览），新选项的默认色用 `nextOptionTone` 轮（蓝、青、黄、橙、绿、紫、粉、红、橄榄、灰）。
- 选项色只用在选项 / 标签 / 填色 / 视图色块上；状态（正常 / 注意 / 异常）仍用 §1.1 的主色系和三种点缀色。

## 2. 尺寸、字体与形状

| 部位 | 规则 |
|---|---|
| 控件高度 | 标准 36px（`--aui-control-height`：按钮、输入框、下拉、分段选择），小号 28px（`size="sm"`，表格行内按钮、工具栏）；手机上标准控件自动变 40px；**触屏尺寸 44px**（`--aui-control-height-touch`）给手机和公开页上要点的东西：按住说话、公开页的按钮 / 输入框 / 密码格（`.aui-public` 外框在 ≤760px 自动套用），组件里不写死 44px。标签（20–22px）不算控件 |
| 圆角 | 控件 8px（按钮、输入、菜单项），28px 及以下的控件和标签 6px，提示气泡 6px，面板 / 卡片 / 弹框 / 说明卡 12px；全圆只给数字角标、圆点、头像、进度条；组件里不写死别的圆角 |
| 字体 | 8 档字号：大数字 28 · 页面 / 记录标题 22（手机 20）· 区块大标题 18 · 卡片标题 14.5 · 正文 14 · 表格 / 控件 / 次要 13 · 标签 / 按钮小号 12.5 · 备注 / 表头 12，行高定死（token `--aui-fs-display` … `--aui-fs-note`，工具类 `.aui-text-display` … `.aui-text-note`）；字重只有 400 正文 · 500 按钮 / 标签 / 强调 · 600 所有标题、表头和大数字；全部乘全局字号系数 `--aui-font-scale`；数字一律等宽，单位小一号次要色。例外只有：对话框标题 16、KPI 数字 28 / 24 / 20、键帽 / 头像 / 角标这类小标记 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24px 阶梯；相关控件紧邻，独立区域留白；桌面左右 16px、手机 12px |
| 密度 | 默认 `density="compact"`：表格行 40px；`comfortable` 48px |
| 表面 | 1px 边线 + 表头底色，阴影很轻；不层层套卡片 |
| 表头 | DataTable 和多维表格同一套：高 40px、12px / 600、次要色、浅灰底，**不加字距**（中文加字距不好看）；变量 `--aui-table-head-height / -size / -weight / -color / -bg`（tokens.css），自己画的表头也用它们 |
| 行与选择 | 行高三档：紧凑 40 / 宽松 48（默认）/ 两行 56，第二行信息只在两行档出现；部分勾选时表头半选「−」；批量操作 = 底部居中浮条（白底、圆角 12、浮层阴影，「已选 N 条 · 动作 · ✕」），不推动表格，选中行的操作列照常可点；分页脚左「共 N 条」/「已选 2 / 共 N 条」，当前页主色浅底，游标列表「已显示 1–20 条」；手机上 DataTable 每行一张卡片 |
| 选中 | 侧栏、列表、表格的选中项用主色浅底 + 文字加粗，不加彩色竖条 |
| 宽度 | 内容铺满；侧栏 232px、折叠 64px、顶栏 48px、菜单行 34px（手机抽屉 min(304, 84vw)、行 44px）；模块工作区（T15 / T17）图标栏 60px + 目录 232px、标题栏 48px；公开页（T16）居中一栏 688 / 440px；其余页面不加居中 `max-width` 或大幅欢迎横幅 |

### 全局字号

顶栏 `AppearanceButton` 里选字号（只要字号可单独放 `<FontSizePicker />`）：小号、中号、中大号（默认）、大号、特大号。导航、工作标签、表格、详情、表单、弹窗和图表文字一起变；按 `storageKey + ":font-size"` 保存，与色卡分开存。指定初始档位传 `defaultFontSize="large"`。业务页写固定字号时用 `calc(14px * var(--aui-font-scale))`。

### 2.1 表单控件

| 部位 | 规则 |
|---|---|
| 输入框 / 下拉的状态 | 静止边框 `--aui-field-border`（线色和控件边框色之间）、悬停 = `--aui-control-border`、聚焦 / 展开 = 主色边 + 3px 主色浅光圈 `--aui-focus-ring`；出错 = 异常色边（聚焦时 `--aui-focus-ring-danger`）+ 下方一行带图标的说明；禁用 = 次级面底 + 备注色字；只读 = 无边框、`--aui-wash` 底 |
| 下拉（`Choice` / `MultiChoice`） | 一种触发器 + 一种弹层：弹层圆角 12、阴影 `--aui-pop-shadow`、行高 32（`--aui-option-row`）、选项圆角 6、整行悬停（`--aui-option-hover`）；单选的勾在右，多选的勾选框在左 + 底部「已选 N 项 · 清空」；多于 6 项出搜索，分组小标题，灰掉的写原因，搜不到就地新建；清空是悬停出现的 ×，不是第一项假选项；选项有颜色就显示成标签，人员是头像 + 名字 + 部门 |
| 多选的值 | 可删标签（× 悬停才变深）；字段 / 表单里换行，28px 小号（筛选、格子）一行、放不下收成 +N；点外面就保存，不要「完成」按钮 |
| 表单里的单选 | ≤ 6 个短选项平铺成带颜色的标签按钮（`ChoiceTags`），选中 = 主色描边 + 光圈 + 勾；多了用 `Choice`；没有颜色的短单选用 `RadioGroup` |
| 日期 | 值后面跟「周四 · 明天」；到期字段（`deadline`）明天到期用注意色、过期用异常色；弹层顶上「今天 / 明天 / 下周一 / 一周后 · 清空」；今天 = 主色字 + 小圆点、已选 = 主色实底、键盘焦点 = 主色描边；日期 + 时间在月历右边有半小时一档的时间列；空框不放示例日期 |
| 勾选类 | 勾选框 16px 圆角 4、单选圆点 16px（选中 5px 主色环）；选中 = 主色实底白勾，半选一横；全 SDK 一种勾选框（`Checkbox`），不用原生 `accent-color`；开关 32 × 18（小号 26 × 14），设置行里放右边、立即生效 |
| 分段选择 | 浅底槽 + 白色凸起的选中块（深色下是稍亮的面板色）；主色实底只留给真正的按钮 |
| 手机（≤ 760px） | 同一个弹层变成底部弹层：遮罩 + 抓手 + 「左 · 标题 · 右」（下拉「取消」、多选「完成」、日期「清空 · 字段名 · 确定」），行高 / 日子格 44px |
| 滚动条 | 全站一套：细、圆头、控件边框色（`--aui-scrollbar-size` 10px，弹层 / 下拉 / 菜单 / 时间列 8px；`--aui-scrollbar-thumb` / `-hover`）。组件里不写 `scrollbar-width: thin` / `scrollbar-color`（Chromium 121+ 写了就退回系统样式），只有「不要滚动条」的横滚条写 `scrollbar-width: none` |

starter「系统 → 表单控件」是五组控件的样板页（浅 / 深色、手机）。

### 2.2 基础元素

| 部位 | 规则 |
|---|---|
| 按钮 | 7 种样式：主（`default`，纯主色、无渐变无投影，一块区域只一个）· 次要（`secondary`，主色浅底）· 描边（`outline`，边 = 输入框同一根 `--aui-field-border`）· 幽灵（`ghost`，**灰字**：工具栏、卡片角）· 文字按钮（`text`，主色字：表格行里 / 行内的动作）· 危险实心（`destructive`，只在确认框）· 危险描边（`destructive-outline`，页面上的删除）。4 档尺寸 40 / 36 / 28 / 24（`lg` / 默认 / `sm` / `xs`），圆角 8 / 8 / 6 / 6，图标 16 / 16 / 14 / 14，字重统一 500，手机标准按钮自动 40。悬停 = 中性 4–6% 叠层（`--aui-hover-overlay`），按下 8–10%，聚焦 = 输入框同一个 3px 光圈；禁用 = 浅灰底 + 淡字（不降透明度），说不清为什么禁用就给 `disabledReason`（按钮仍可聚焦，气泡说原因）；`loading` = 转圈换掉左图标、字可改「保存中…」、宽度锁住、点不动。跳到别处用 `Link`，在原地做事用 `text`；按钮不收 `title`，悬停说明用 `tooltip`，禁用原因用 `disabledReason` |

### 2.3 输入与表单

| 部位 | 规则 |
|---|---|
| 文本框 | 和 §2.1 的下拉 / 日期同一套边框、焦点环、错误样式。`Input` 照旧是裸 `<input>`；给了 `prefix` / `suffix`（图标、单位，备注色写在框里）、`segment`（要选的前缀：区号、币种、https://，框里的一格，中间一条线）、`clearable`（有值且悬停 / 聚焦才出现的浅色圆圈 ×）、`showCount`（右端「12/20」）就包成一个框，ref / id / aria 仍在 input 上。尺寸只有 28（`size="sm"`）/ 36，手机自动 40，公开页（`.aui-public`）44 |
| 多行 | `Textarea` 自动长高 3–10 行（`minRows` / `maxRows`），没有拖拽角；`showCount` / `footer`（工具按钮、快捷键提示）放在框里的底行。跟进、评论共用一种输入框 |
| 出错 | 红边 + 下面一行「图标 + 原因 + 怎么改」（一句话写完，例如「手机号要 11 位、1 开头，例如 138 0013 8000」）；出错那一行替换说明。打字不打断，离开一个框才判这一个 |
| 字段 | `FormField`：标签 13px 次要色 → 控件 → 说明或出错（同一行）→ 右侧字数（`count`）；必填红 *，`optional` =「（选填）」，`help` = 标签后的「?」。`FormSection layout="side"`（设置页：左边标题 + 一句说明，右边字段，分区之间一条线）、`labels="side"`（左标签 112px，手机自动上下排） |
| 提交出错 | `FormDialog` 收到 `FormFieldErrors` 后：两项以上在顶部汇总「有 N 项要改」（每条可点，跳过去并闪一下框，`FormErrorSummary`），每个框红边，焦点到第一个错，底栏左边「N 项要改」 |
| 设置页保存 | 整页一个吸底 `SaveBar`：改了才出现，写「改了 N 处」+ 哪几处 + 放弃 / 保存，手机贴底铺满；改过的字段标签后「已改」（`FormField changed`）；草稿和已保存值用 `useChangeTracker` 管；立即生效的开关（`AsyncSwitch`）不算，不再每个分区一个保存按钮 |
| 数字 | `NumberInput`：等宽数字；表单左对齐、表格 `align="right"`；悬停 / 聚焦才出 ↑↓ 小箭头，↑↓ 加减、Shift 一次 10。1–30 的小整数才用 `NumberStepper`（同一个框，两端 28px 幽灵按钮，到上下限变灰） |
| 金额 | `MoneyInput`：币种是框里的一格（字段定死就只读；默认币种在 `AdminProvider defaults.currency` 设一次，单个字段用 `currency` 覆盖）；打字纯数字，离开加千分位；值存最小单位；一万以上下面写「约 ¥8.6 万」（`approxMoney`）；格子里编辑时币种还在 |
| 电话 | `PhoneInput`：区号一格，`defaultCountry` 传本公司所在地（例如 +86 / +44 / +886，不传时按 `AdminProvider defaults.phoneCountry`）；号码按当地习惯分组（138 0013 8000），值存 E.164（+8613800138000）查重；离开输入框才报错 |
| 百分比 / 滑块 / 评分 | `PercentInput` 框里写 %；格子里（多维表格字段类型 `percent`）「60%」+ 56px 细条（`PercentBar`）。`Slider` 只给大概值（赢率、满意度）：4px 轨道 + 16px 圆点，悬停 / 拖动头上出数值，旁边永远配数字框。`Rating` 星一律实心：亮 = 注意色、没亮 = 浅灰；表单 18px 右边写「较高」，格子 13px |
| 上传 | 只有一种拖放区 `UploadDropZone`：1.5px 虚线 `--aui-field-border`、圆角 12、36px 中性图标块；拖进来变主色实线 + 浅底，写「松手开始上传 N 个文件」；格式和大小写人话（`uploadLimitText`：「图片 PNG / JPG，5 MB 以内」）。表单里单个文件用 `UploadField` 的一行版，传完是文件行（缩略图或类型方块 + 名字 + 大小 + 换一张 / 删除）。队列一行一个文件：4px 主色细条 +「46% · 还要 10 秒」，失败写原因 + 重试，顶上「全部重试」，行上的按钮悬停才出现、触屏常显。照片用 `ImageUploadGrid`（96px 方块，第一张是封面，上传中圆环 + 百分比，失败红边 + 重试，「添加照片 · 还能加 N 张」）。附件面板空的时候只有一个拖放区（`AttachmentGallery onFiles`） |
| 密码 | 一律 `PasswordInput`（等宽、框里的眼睛、大写锁定提醒，出错和文本框一样）；设密码配 `PasswordStrength`（4 段条 + 太弱 / 一般 / 够用 / 很强 + 要求随打字打勾）和「再输一次」实时比对（`PasswordConfirmHint`）；新建账号的初始密码用 `InitialPasswordField`（自动生成 / 我来设，自动的直接显示、可换一个、可复制），不靠「留空 = 自动生成」的暗规则。分格密码 `CodeInput` 格子 44 × 52，出错只变红边 + 抖一下，剩余次数小点 |
| 搜索 | 列表搜索打字就筛（停 0.3 秒，`QueryBar` 默认），去掉「查询 / 重置」，有别的筛选时才出「清空筛选」（`canReset`）；很慢的列表（审计日志）`searchMode="enter"`，框里写「回车搜索」。`hits` 写命中几条，`Highlight` 标出命中字，`shortcut="/"` 聚焦，Esc 清空。`SearchField` / `SearchBox` 同一个框；浏览器自带的粗黑 × 不显示 |

starter「系统 → 输入与表单」是这批的样板页（浅 / 深色、手机）。

### 2.5 图表与仪表盘

| 部位 | 规则 |

### 2.6 协作、分享与媒体

- **一屏一个实心主按钮**：其余描边 / 幽灵。分享弹框「复制」实心、「完成」描边；AI「采用」描边主色字；审批「批准」实心、「驳回」描边异常色。

### 文件大小与类型

- **大小只有一种写法：1024 进位**（1 KB = 1024 B、1 MB = 1024 KB，标 KB / MB / GB——和 Windows、手机相册看到的一样）。上限也按它写：`20 * 1024 * 1024` 显示「20 MB」，不写 `5_000_000` 这种十进制数（会显示成「4.8 MB」）。界面上的大小一律用 `formatBytes`（MB 起一位小数，整数不带「.0」），不自己除 1024 / 1000。
- **类型写人话，不露 MIME**：单个文件用 `fileTypeName(name, mime)`（「图片 PNG」「视频 MP4」「PDF 文档」「Word 文档」「Excel 表格」「PPT 演示文稿」「压缩包 ZIP」），上传限制用 `acceptLabel(accept)`（`["image/png", "image/jpeg"]` →「图片 PNG / JPG」，`[]` →「任意文件」）。文件方块上的短标签仍是 `fileTypeLabel`（PDF / XLS）。

### 表单出错

逐项出错：错误写在那个框下面（图标 + 原因 + 怎么改）、框变红（`aria-invalid`），提交时两项以上在表单顶部汇总「有 N 项要改」（可点跳过去）、底栏左边写「N 项要改」，焦点到第一个出错的框并滚到可见处（手机上不会「点了没反应」）。`FormDialog` 里由宿主在 `onSubmit` 里 `throw new FormFieldErrors({ [控件 id]: "请填客户名称" })`（或给 `fieldErrors`），`FormField` 按 `htmlFor` 自己取；不把字段错误拼成一行堆在表单底部。整表级的错（网络、疑似重复）照常 `throw new Error(…)`，显示在表单底部并滚到可见处。公开填写页（`PublicForm`）同一规矩：离开一题才判这一题，点「提交」判全部。

### 3.1 页面骨架

```tsx
<PageHeader title="用户管理" description="……" actions={<Button>新增用户</Button>} />
<PageBody>
  <KpiGrid>…</KpiGrid>
  <ResourcePanel …>…</ResourcePanel>
  <SectionCard title="说明">…</SectionCard>
</PageBody>
```

- 页面 = `PageHeader` + `PageBody`。页面头之后的兄弟区块放进 `PageBody`：纵向栈、统一 16px 间距，不要在页面里补 `marginTop`。
- **列表页撑满一屏：`<PageBody fill>`**。工作页至少一屏高，`PageBody` 的最后一块伸到底：`ResourcePanel`（含 `DataTable`）、`SplitLayout` 主栏里最后的 `ResourcePanel`、装 `ListDetailLayout` 的 `Panel`。伸开后表格区占满卡片、分页贴卡片底；空 / 加载 / 出错状态在表头与分页之间上下左右居中；有数据时行高不变，超过一屏整页滚动。顶栏和工作标签条的高度由 `AdminShell` 自己量（字号、窗口变化时重量，Windows 缩放下向上取整，不会多出 1px 滚动）。限制：`PageBody` 要是工作页的直接子元素（`PageHeader` 的兄弟），`TabbedPage` 分区里暂不支持；不是列表的页面（设置、看板）不用 `fill`。
- `PageHeader` 不显示大标题（侧栏 / 工作标签 / 面包屑已有页名，标题只给读屏；没有外壳的页面用 `showTitle`），`description` 收成右上角「?」（`HelpTip`，悬停 / 聚焦 / 点按显示）；`Panel` / `ResourcePanel` 的 `description` 同样收成标题旁的「?」。页面里不写介绍段落。页面按钮和「?」自动并进页面 / 分区第一块（面板、列表、看板分区）的标题行，不单独占一行（5.3）；第一块是 KPI 卡这类没有标题行的，放进分区标签那一行的右端（5.4）；都没有时才在原位一行靠右。`DashboardSection` 的说明也收成「?」。指标卡（`KpiCard` / `MetricCard`）是紧凑的：不设最小高度、内边距 10–14px。
- `PageHeader` 的操作在桌面固定右上（操作块最多占三分之二宽、块内折行）；≤760px 换到标题下方左对齐。
- 一个菜单项合并几个页面用 `TabbedPage`：页头只出现一次，下面是页内分区标签；分区里的页面照写 `PageHeader`，会自动收成「说明 + 操作」一行。分区切换保留状态，单个分区出错只坏这一块。
- 只读事实用 `DescriptionList`（默认横排：标签 96px 备注色 13px、值 13.5px 正文色；`columns` 1/2/3，`full` 占整行，≤760px 一列、标签 84px；窄卡片 / KPI 下面用 `layout="stacked"` 标签在上；空值「—」）。
- 主壳：顶栏当前页标题单行省略；当前菜单项自动滚进可见区；侧栏底色画满整列；`documentTitle` 同步浏览器标题。
- 标签条放不下时（页内 `Tabs`、工作标签）：不出系统滚动条，有内容的一侧文字渐隐，滚轮横向滚动，选中项自动滚进可视区；页内标签右端出「更多 ⌄」（列出全部分区），工作标签右端常驻「N ⌄」（全部已打开的页面，可搜，关闭其他 / 关闭右侧；右键同样菜单，中键关闭）。没有圆形箭头。业务页不要自己加滚动条样式或左右按钮。

| 设置 | 设置页 `SideNavLayout`：左 200 直接在画布上（不包卡片），分组小标题 + 34px 行，改过琥珀点、出错红叹号，窄屏吸顶胶囊；整页一条吸底 `SaveBar`，每节不各放保存。表设置这类抽屉 `SettingsSheet`：880 宽、左 184 分节、右边一次一节、底部「改了 N 处 · 取消 · 保存」 |
| 列表 → 详情 | 窄屏（≤ 760）统一两步：先列表，点一行只看详情，左上 ← 回列表，右栏收进详情的 ⋯（`ListDetailLayout` / `WorkspaceLayout narrow="steps"` + `onBack`）。单栏阅读页（知识库文档）除外 |

### 3.2 资源面板

```tsx
import { ResourcePanel, QueryBar, DataTable, InlineAlert } from '@adminui/react';

<ResourcePanel
  title="用户列表"
  count={loading || error ? undefined : result?.total}
  description="当前显示符合筛选条件的用户"
  actions={refreshButton}
  filters={<QueryBar {...queryProps} />}
  feedback={staleError && (
    <InlineAlert tone="error" title="刷新失败，当前数据可能已过期" action={retryButton}>{staleError}</InlineAlert>
  )}
>
  <DataTable {...tableProps}
    emptyKind={hasFilters ? 'no-results' : 'empty'}
    emptyAction={hasFilters ? clearFiltersButton : createButton} />
</ResourcePanel>
```

- `count` 只接受相同筛选下的准确总数；`0` 会显示，未知 / 游标列表不传。不能拿当前页长度冒充总数。
- `filters` 放 `QueryBar`；`feedback` 放选中提示或异常提示（批量操作用 `DataTable bulkActions`，底部浮条自带）；`children` 放 `DataTable`。
- `InlineAlert`：`info / success / warning / error`；error 用 alert 语义，其余 status；不自动消失，恢复按钮放 `action`。
- `DataTable` 的 `emptyKind` 默认 `empty`；筛选无结果传 `no-results` 并给清空筛选按钮。首次请求失败不能当空列表。

### 3.3 客户门户

给**客户**用的用户中心（自助查用量、拿 Key / 订阅、续费）和员工后台是两种东西：客户每次来只办一件事。用 `AdminShell variant="portal"`。

**外壳**
- 没有多页签、没有面包屑，只挂当前页（URL 可分享）。
- 菜单一级 ≤ 8 项、最多两级，按任务命名（「密钥与接入」而不是「分组」「渠道」）。
- 手机：`mobileNav` 放 ≤ 4 个常用入口到底部栏，第 5 个「更多」打开完整菜单。悬浮客服用 `bottom: calc(16px + var(--aui-bottom-nav-offset, 0px))` 避开底部栏。
- 顶栏只放一个主操作（购买 / 续费）和通知、深浅色。

**首页从上到下**
1. 提醒条：只在有事时出现（7 天内到期、额度快用完、待支付、客服新回复），每条带能直接办的按钮。
2. 我的套餐卡：名称、状态、到期日、续费按钮；额度用 `QuotaMeter` 写「已用 / 总量 + 何时恢复」，≥ 80% 注意色、用完异常色并说下一步。
3. 接入卡：Key / 订阅链接打码 + 一键复制、下载客户端；新客户看到 `SetupChecklist`（按真实数据自动打勾，可收起，不弹强制教程）。
4. 用量趋势：一张图 + 「查看明细」。
5. 最近订单 / 其他服务：最多 3 条，没有就整块不显示。
6. 帮助：教程、常见问题、客服，位置固定。

首页数字 ≤ 3 个，不做 KPI 墙、仪表盘、饼图；过期 / 用完要给续费或恢复按钮，不能只显示红色数字。

依据：NN/g（一屏可行动、渐进披露、汉堡菜单降低发现率、情境帮助优于强制教程）、Material 3 底部栏 3–5 项、Shopify App Home / Setup guide、Baymard 自助账户页、DigitalOcean / 阿里云 / Cloudflare 控制台、Claude / OpenRouter / DeepSeek 用量页、V2Board / Xboard 用户中心。

## 4. 动效

后台动效只做操作反馈、加载状态和短距离过渡，不做装饰。

| 效果 | 用法 | 行为 |
|---|---|---|
| 按钮按压 | `Button` 自带 | 按下轻缩放 120ms，禁用按钮无反馈 |
| 弹框 / 下拉 / 通知入场 | `Dialog` / `FormDialog` / `Choice` / `useNotify` 自带 | 淡入 + 短位移 180ms；关闭即时，不等动画 |
| 手机导航菜单滑入 | `AdminShell` 自带 | `translateX` 240ms，遮罩淡入 |
| 局部入场 | `MotionReveal effect="fade" \| "rise" \| "scale"` | 默认 rise 6px；`replayKey` 变化时重播，不重挂载子树；`delay` 0–300ms |
| 加载占位 | 表格 `DataTable loading`（自己的表头 + 骨架行），列表 / 卡片 `ContentSkeleton`，零散的 `Skeleton lines={3}` / `SkeletonBlock` | 参差宽度，离屏 / 页面隐藏暂停；刷新用 `refreshing` / `TopProgress`（旧数据留着） |
| 不确定进度 | `LoadingDots label="正在读取"` | 只表达「在进行」，不冒充进度条 |

```tsx
{loading
  ? <Skeleton lines={3} label="正在加载清单" paused={!active} />
  : <MotionReveal effect="rise" replayKey={revision} active={active}><Content /></MotionReveal>}
```

- 默认跟随系统「减少动态效果」；`AdminProvider motion="none"` 关闭本根全部 SDK 动画（不持久化）。`useAdminMotion()` 返回当前是否允许 JS 动画。
- 只用 `transform` / `opacity`；不常驻 `will-change`。
- 动画结束不能当作请求成功或按钮解锁的条件；不要用 React `key` 重挂载表单来重播。
- 隐藏的工作页传 `active={false}` / `paused`。粒子、扫光这类装饰效果按需用 dongxiao，不在后台日常页面加载。

依据：IBM Carbon Motion、web.dev 高性能动画、Radix Animation、MDN `prefers-reduced-motion`。

## 5. 可访问性与响应式

- 普通文字对比度 ≥ 4.5:1；关键内容不降透明度。状态同时有图标 / 文字。
- 图标用 Lucide SVG，禁 emoji；图标按钮用 `IconButton`（`label` = aria-label + 提示气泡）。不用原生 `title`：悬停说明一律是 SDK 的深色气泡（`Tooltip` / `tipProps`），手机和键盘也能看到。
- 手机：筛选自动换行；页大小选择独占一行；宽表只在表格容器内横滚，整页不横向溢出；弹框长表单可滚动，关闭和保存可触达；不依赖 hover。
- 只朝一个方向滚的容器两个方向都写明（`overflow-x:auto; overflow-y:hidden` 或反过来），焦点框用 `outline-offset:-2px` 画在里面。
- 手机和公开页上能点的东西用触屏尺寸 `--aui-control-height-touch`（≥ 44px）。
- `.adminui` 里原生 `<button>` 的文字色默认跟随父元素；这条重置写在 `:where()` 里（优先级 0,1,0），组件自己写的颜色规则（`.adminui .aui-xxx`，0,2,0 起）总能生效，不需要再用 CSS 变量绕开。
