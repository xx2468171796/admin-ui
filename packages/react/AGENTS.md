# adminUI — 给改这个包的人 / AI

先读 ../../AGENTS.md、[AI-RULES.md](AI-RULES.md)、[INTEGRATION.md](INTEGRATION.md) 和 `src/catalog.ts`。



- 组件是跨项目契约：业务接口、数据库、账号规则不进 SDK。样式只作用在 `.adminui` 内，所有弹层挂所属 Provider 的 portal。重依赖只从独立子路径导出，不进根入口。
- 颜色只来自色卡（`src/palette.ts`）：一个主色系 + 注意 / 异常 / 信息三种点缀色，不加装饰色条；控件 36px / 小号 28px，圆角 8 / 12px。新组件先确认属于 AI-RULES §0 的套件，再用 token 写。
- 公开能力改动同步：`src/catalog.ts`（exports + rule）、对应文档、starter 示例、[CHANGELOG.md](CHANGELOG.md)（写「同事会注意到什么 + 风险」）。删除导出时在 CHANGELOG 升级指南写替代。
- 页面布局以已审定的模板为准（starter「页面模板」各页，截图 `design/templates/tNN-*.png`）：改模板的块或布局前先做演示（静态页或 starter 页）给产品负责人看，通过后再写代码，改完截图对照。
- 自我进化闭环：新组件 演示 → 产品负责人通过 → SDK（组件 + 文档 + catalog + 单测 + 浏览器测试 + starter + 留演示截图）→ 发版；漂移门禁 `scripts/ui-audit.mjs`（bin `admin-ui-audit`），加 / 改规则同步 `RULES`、`catalog.ts` 的 `TOOLS` 和 `test/ui-audit.test.ts`，starter 必须 `npm run audit:starter` 零错误。
- 文档只写当前行为，不写版本历史标签（历史只在 CHANGELOG）；中文、具体、可复制。
- 版本 tag 前缀 `adminUI-v`，包名 `@adminui/react`；改版本号时同步 README / INTEGRATION 里的固定版本。

## 门禁：改哪里跑哪个
